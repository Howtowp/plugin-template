Starter skeleton for How to WP plugins.

== Description ==

Plugin Template is the starting point for new How to WP plugins: PSR-4 modules, Settings API page, REST route,
Abilities API sample, optional AI stub, WooCommerce HPOS declaration and an interactive block.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`, or install the zip from Plugins → Add New → Upload.
2. Activate it from the Plugins screen.
3. Open Settings → Plugin Template.

== Frequently Asked Questions ==

= Does this plugin update itself? =

No. Download new versions from https://howtowp.ir and upload them.
